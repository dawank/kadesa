# Dokumentasi Proyek KADESA

Repositori ini memuat implementasi frontend resmi aplikasi **KADESA (Sistem Kehadiran Aparatur Desa)** berdasarkan PRD dan Aturan Bisnis Final KADESA.

## Indeks Dokumen

1. [PRD KADESA](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/prd.md)
   * Dokumen spesifikasi fungsional, matriks permission, alur kerja, dan invariant bisnis resmi (Terkunci).
2. [00-project-status.md](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/00-project-status.md)
   * Status workflow resmi (Planning: CLOSED, Frontend: LIVE TEST READY, Backend: PENDING).
   * Ringkasan capaian, pengujian, hasil audit, dan rekomendasi acceptance gate.
3. [01-frontend-implementation-report.md](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/01-frontend-implementation-report.md)
   * Laporan terperinci arsitektur frontend, daftar komponen/halaman, service adapters, design system, validasi, aksesibilitas, dan kontrak service.
4. [02-frontend-acceptance-audit.md](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/02-frontend-acceptance-audit.md)
   * Dokumen Audit Final & Acceptance Gate Frontend KADESA: matriks kriteria penerimaan PRD (PASS/FAIL/NOT VERIFIED), bukti kode & tes, perbaikan temuan, dan batas frontend.
5. [03-frontend-live-test.md](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/03-frontend-live-test.md)
   * Panduan & Log Live Test: URL lokal aktif, cara login akun demo, dan 5 skenario alur kerja siap uji manual.
6. [architecture-decisions.md](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/architecture-decisions.md)
   * Rekam Keputusan Arsitektur (ADR): pemisahan Role vs Jabatan, Configuration Resolver, state machine DL, isolasi mock adapter, enkapsulasi demo mode, dan mutasi koreksi non-destruktif.
7. [known-issues.md](file:///d:/DAWANK/APLIKASI_TEST/KADESA/docs/known-issues.md)
   * Batasan frontend, catatan pengujian browser, batasan keamanan geofence/evidence, dan kontrol keamanan yang membutuhkan tahap backend.
